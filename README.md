# AI-Powered Chatbot 🤖

## About
A beginner-level AI-powered chatbot built using Python, NLTK and Machine Learning. It uses text preprocessing and a Naive Bayes classifier to predict responses to user inputs.

## Technologies Used
- Python
- NLTK
- Scikit-learn
- CountVectorizer
- Multinomial Naive Bayes

## Features
- Text preprocessing
- Tokenization and lemmatization
- Stopword removal
- Machine learning-based response prediction
- Interactive command-line chatbot

## Installation
pip install -r requirements.txt

## Run the Project
python main.py
